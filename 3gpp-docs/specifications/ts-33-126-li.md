# TS 33.126 - Lawful Interception (LI) Architecture

## Overview
TS 33.126 defines the lawful interception architecture and procedures for 5G networks, including the interfaces and protocols used for intercepting user communications.

## LI Architecture Components

### Core LI Functions
1. **LI-ADMF (Administration Function)**: Manages LI requests and configuration
2. **LI-DF2 (Delivery Function 2)**: Handles content of communications
3. **LI-DF3 (Delivery Function 3)**: Handles intercept related information
4. **LI-X1**: Interface between LI-ADMF and network functions
5. **LI-X2**: Interface between network functions and LI-DF2
6. **LI-X3**: Interface between network functions and LI-DF3

### SMF-UPF LI Interface
The SMF-UPF interface for LI involves:
- Session context management with LI parameters
- Traffic steering rules for intercepted flows
- Usage reporting for LI purposes
- Error handling and status reporting

## LI Traffic Steering

### Content of Communications (LI-X2)
- Voice calls (VoLTE/VoNR)
- Video calls
- Data sessions
- SMS messages
- IMS services

### Intercept Related Information (LI-X3)
- Session establishment/release
- Location updates
- Service requests
- Authentication events
- Charging information

## LI Security Requirements

### Encryption
- All LI data must be encrypted in transit
- Use strong encryption algorithms (AES-256)
- Key management through secure channels

### Authentication
- Mutual authentication between LI entities
- Certificate-based authentication
- Regular key rotation

### Authorization
- Role-based access control
- Audit logging for all LI operations
- Regular access reviews

## Error Handling

### LI Error Codes
- **LI-001**: Invalid LI session ID
- **LI-002**: Unauthorized LI request
- **LI-003**: LI session not found
- **LI-004**: Invalid target identity
- **LI-005**: LI session expired
- **LI-006**: Delivery function unavailable
- **LI-007**: Encryption/decryption failed
- **LI-008**: Invalid LI message format

### Error Response Format
```json
{
  "error_code": "LI-001",
  "error_message": "Invalid LI session ID",
  "timestamp": "2024-01-15T10:30:00Z",
  "li_session_id": "li-session-12345",
  "retry_after": 30
}
```

## Compliance and Legal Requirements

### Data Retention
- LI data must be retained for specified periods
- Secure deletion after retention period
- Audit trail for data lifecycle

### Privacy Protection
- Minimize data collection
- Purpose limitation
- Data subject rights (where applicable)

### Reporting
- Regular compliance reports
- Incident reporting
- Performance metrics
